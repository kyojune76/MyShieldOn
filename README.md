# MyShieldOn

MyShieldOn is a lightweight Android security check tool that helps users detect key security risks with a single tap.  
It checks for rooting, unauthorized apps, APK tampering, ADB mode status, OS security patch level, and more.

Key features:
- One-touch scan for rooting status and unverified apps.
- Detects APK files with modified or invalid signatures by comparing known hashes of major financial and popular apps.
- Verifies installation sources, developer options, and permission misuse.
- Supports older Android versions to protect devices with outdated security patches.
- Open-source signature database allows the community to maintain and expand threat coverage.

MyShieldOn helps everyday users stay aware of their device security and acts as a deterrent against mobile threats.  
It is designed to improve mobile hygiene and can be used in BYOD policies, research, and education.
